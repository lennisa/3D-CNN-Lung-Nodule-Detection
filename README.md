# Lung Nodule Detection using 3D CNN

## Overview

This project implements a 3D Convolutional Neural Network (3D CNN) for pulmonary lung nodule detection using CT scan images to assist early lung cancer screening.

## Features

- 3D CNN architecture
- CT scan preprocessing
- Lung nodule classification
- Model training and evaluation

## Tech Stack

- Python
- TensorFlow / PyTorch
- NumPy
- OpenCV
- Jupyter Notebook
